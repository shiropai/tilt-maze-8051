## 第 1 步：硬體待確認事項（看板子就能回答）

| # | 問題 | 怎麼看 | 答 |
|---|---|---|---|
| 1 | **晶片型號** | 看 8051 晶片上印的字（例如 AT89S51、AT89S52、STC89C52RC） | |
| 2 | **晶振頻率** | 晶片旁邊銀色小鐵殼上印的數字（11.0592 或 12.000） | |
| 3 | 點矩陣的 CS 能接 **P2_5** 嗎？ | 看杜邦線能不能接到 P2_5 | |
| 4 | 七段顯示器是 **4 位還是 8 位**？ | 數一下有幾個數字 | |
| 5 | 蜂鳴器是**有源還是無源**？ | 直接接 5V：一直嗶 = 有源；沒聲音或只喀一聲 = 無源 | |
| 6 | 兩顆按鍵能接 **P3_2 / P3_3** 嗎？ | 看板子上的按鍵接到哪裡 | |
| 7 | **燒錄器與燒錄軟體**叫什麼？ | 例如 ProgISP、STC-ISP、AVRDUDE + USBasp；有沒有指令列版本？ | |

⚠ **第 1 項最重要**：目前程式約 4.6 KB。如果晶片是 4 KB flash（例如 AT89S51），會燒不進去或跑不正常，請先告訴我。

## 第 2 步：M1 硬體整合測試

燒錄 `main.hex` 後，**開機時板子要平放 1 秒**（程式會在這段時間校正零點，OLED 最下面顯示 `HOLD FLAT...`）。
電腦端打開序列埠工具，設定 **9600 baud、8N1**。

| # | 測試動作 | 應該看到 | 結果（OK / 不對：描述） |
|---|---|---|---|
| 1 | 開機 | OLED 顯示 `TILT MAZE` / `M1 HW TEST`，蜂鳴器「嗶」一聲（約 0.15 秒、中音） | |
| 2 | 看序列埠 | 收到 `TILT MAZE M1 READY` | |
| 3 | 傾斜板子 | 點矩陣上有一個點會滾動；滾到邊界時有短促的「嗶」 | |
| 4 | **向右傾** | 點往**右**滾？ | |
| 5 | **向前傾**（遠離自己那側往下） | 點往**下**滾？ | |
| 6 | 點從左邊滾到右邊 | 兩片點矩陣接得起來？還是跳到另一片的另一端（左右顛倒）？ | |
| 7 | 傾斜板子看 OLED | `AX`、`AY` 數字跟著變（平放時接近 0） | |
| 8 | 轉可變電阻 | OLED 的 `POT` 改變，七段**左 4 位**也跟著變（如果七段只有 4 位，就看不到這項，正常） | |
| 9 | 手靠近 IR 感測器 | OLED 的 `IR` 數字改變（記下手遠、手近大概的數字） | |
| 10 | 等幾秒 | 七段**右 4 位**每秒加 1 | |
| 11 | 看 LED | 8 顆 LED 慢慢變亮變暗（呼吸燈） | |
| 12 | 按 **INT0**（P3_2） | 球停住、LED 全亮、響一聲**低音**、序列埠收到 `PAUSE`；再按一次恢復，響一聲中音，收到 `RESUME` | |
| 13 | 按 **INT1**（P3_3） | 點回到中央、響一聲短促**高音**、序列埠收到 `CENTER` | |
| 14 | 序列埠送出字元 `r` | 點回到中央、收到 `RESET` | |
| 15 | 整體手感 | 球太快／太慢／太飄？畫面會不會卡頓？ | |

### 常見狀況（先記下來，回來交給 Claude Code 修）
- 完全沒反應、OLED 不亮 → 晶片型號、晶振可能不對，或程式太大放不下
- 序列埠是亂碼 → 晶振可能是 12 MHz，不是 11.0592
- 球方向相反 → 只要改 `inc/board.h` 的 `TILT_X_SIGN` / `TILT_Y_SIGN`
- 兩片點矩陣左右顛倒 → 只要改 `inc/board.h` 的 `MATRIX_NEAR_IS_LEFT`
- 蜂鳴器沒聲音或只有「喀喀」聲，或每種聲音都一樣高 → 可能是有源蜂鳴器，記下來
